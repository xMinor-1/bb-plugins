# Отмена в плагине: откатывать только затронутое

- Кнопка «Отменить» возвращает только записи, которые тронуло действие (было значение
  или не было — удалить), а не снимок всего хранилища. Снимок целиком, нажатый через
  пару минут, молча стирает правки других записей за это время. Так было в
  sticker-note 0.1.0, исправлено в 0.1.1 (31.10.2026).
- Проверка: тронуть запись A, потом поменять B, отменить A — правка B на месте.
