# Сигналы realtime от сервера плагина

- Сигнал, по которому панель перечитывает данные, слать только когда данные изменились, а не на
  каждое чтение. Иначе чтение → сигнал → чтение: в mcp-catalog 31.10.2026 открытая панель дала
  8373 вызова RPC за несколько минут. Проверка — `handlers: N calls` в `bb plugin list` до и после
  20 секунд с открытой панелью.
