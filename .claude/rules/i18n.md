# Интерфейс плагинов — по-английски и по-русски

Решение владельца 31.10.2026: интерфейс каждого плагина на двух языках с
переключателем. Это заменяет фразу раздела «Язык» в `CLAUDE.md` о том, что
строки интерфейса только по-английски; остальное в том разделе в силе.

## Модуль

- Канон — `shared/i18n.tsx`. В плагине лежит его точная копия `lib/i18n.tsx`,
  импорт `@/lib/i18n`. Плагины собираются и ставятся по одному, импорт из-за
  пределов каталога плагина не сработает.
- Правка модуля — только в `shared/`, затем `scripts/check-i18n.sh --sync`.
  `scripts/check-i18n.sh` без флага проверяет, что копии совпадают.
- Язык общий для всех плагинов репозитория: ключ `xminor-plugins.lang` в
  localStorage страницы bb. Пока никто не выбрал — язык браузера: русский,
  если первый язык браузера русский, иначе английский.
- Переключатель `<LanguageSwitch />` — в шапке или настройках каждой панели.
  У плагина без своей панели переключателя нет: он следует выбору в других.
- Тексты — `defineMessages(en, ru)` рядом с компонентом или в
  `src/messages.ts`. В компоненте `useMessages`, вне компонентов (тосты, текст
  для буфера обмена) — `messagesNow`. Числа и даты — `Intl` с
  `intlLocale(lang)`, множественное число — `pluralRu`.
- Сервер модуль не импортирует: там нет React и браузера.

## Что переводить

- Переводится всё, что человек видит в интерфейсе bb от плагина: панели,
  диалоги, тосты, пустые состояния, подсказки, `aria-label` и `title`, текст,
  который плагин кладёт человеку в буфер обмена.
- Остаются по-английски: `bb.description` и README плагина (каталог
  международный), комментарии в коде, тексты для агентов (описания
  инструментов, скиллы, ответы инструментов), вывод CLI, подписи
  `bb.settings.define` (их рисует bb), идентификаторы и ключи.
- Фразу для панели, которую пишет сервер, лучше вернуть структурой (код и
  числа) и собрать в панели. Если собирать на сервере — панель передаёт `lang`
  во входе RPC.
- Заголовки, которые регистрируются при загрузке (`navPanel`, команды), берут
  `getLang()` в момент регистрации; смена языка в них видна после перезагрузки
  страницы.
- Русский — живой: «Сохранить», а не «Сохранение»; без канцелярита. Слова bb:
  тред, окружение, проект, агент, модель, машина.

## Проверка и выпуск

- `scripts/check-i18n.sh`, `npx tsc --noEmit`, тесты плагина, `bb plugin build .`.
- Панель в headless-браузере в обоих языках: переключатель работает, строки не
  вылезают из кнопок, английских остатков в русском нет.
- Перевод — новая минорная версия плагина. В README плагина одна строка:
  интерфейс на английском и русском.
