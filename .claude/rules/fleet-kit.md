# Fleet Kit

- Тег `fleet-kit/vX.Y.Z` — это раздача: источник пульта стоит на широком диапазоне, и новый тег доезжает до всех машин сборки на ближайшей сверке, по умолчанию за 30 минут, без выпуска сборки. Ставить его только по явному слову владельца. Общее правило «спрашивать не нужно» из раздела «Выпуск версии» на пульт не распространяется.
- Новая версия манифеста, которая требует нового пульта, выходит после тега пульта: старый пульт отвергнет незнакомые ключи.
