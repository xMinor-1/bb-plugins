# Частичная правка через zod 4: не `.partial()` от схемы с умолчаниями

- В zod 4 `schema.partial()` подставляет `.default()` вместо отсутствующих ключей:
  `z.object({ a: z.string().default("x") }).partial().parse({})` даёт `{ a: "x" }`. Вход RPC
  «сохранить часть настроек» с такой схемой приходит на сервер с умолчаниями, и
  `{ ...сохранённое, ...вход }` молча их затирает. В tracker-board 07.11.2026 смена вида доски
  сбрасывала выбранную доску и список недавних, нашёл смоук после перезагрузки страницы.
- Для правки — отдельная схема: каждое поле `.optional()` без `.default()`. Тест: сохранить одно
  поле и проверить, что остальные на месте.
