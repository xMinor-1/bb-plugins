# Qlik Sense

- Инструменты Qlik агент получает только через `bb.agents.registerTool` + `configure` по паре
  провайдер и модель. `opencode.json` плагин не пишет: в корпоративной сборке это зона fleet-kit.
- Сервер bb в Qlik не ходит и данных компании не хранит: сервер может стоять вне корпоративной сети.
  Вход, пароль и каталог живут в host-части (`src/host.ts`) на машине, где работает агент.
- Отказ во входе — флаг в `state.json` на машине агента, переживает перезапуск воркера. Снимают его
  только новый пароль или кнопка «Try once more». Автоматических повторов входа не добавлять:
  домен блокирует учётку после нескольких ошибок.
- Галочки каталога — граница доступа агента, а не избранное (решение владельца 31.10.2026).
- Репозиторий публичный: в коде, тестах и README нет адресов Qlik компании, логинов и id приложений.
  Примеры — `corp/*`, `CORP\tester`, `qlik.example.com`.
- После правок: `npm test`, `npm run test:e2e` (Qlik Core в docker), `bb plugin build .` и проверка,
  что `dist/server.js` и `dist/host.js` импортируются.
