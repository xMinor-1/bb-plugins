# Вёрстка панели плагина: ширина и перемонтирование

- Брейкпоинты Tailwind (`md:`, `lg:`) смотрят на окно, а не на панель: при 900 px
  окна панель рядом с сайдбаром bb шириной около 540 px. В exchange-mail 0.4.0
  `md:grid-cols-7` дал на 900 px колонки по 70 px, текст вылезал из карточек
  (31.10.2026). Сетку, которая зависит от места, задавать от ширины контейнера:
  `repeat(auto-fill, minmax(max(7.5rem, calc((100% - 6 * gap) / N)), 1fr))` —
  не больше N колонок и не уже минимума.
- Ниже примерно 768 px bb переходит на мобильную раскладку и монтирует страницу
  плагина заново: состояние компонентов (выбранная неделя, вкладка) сбрасывается.
  Headless-проверку на узких ширинах вести так, чтобы этот сброс не принимать за
  ошибку, а нужное состояние, если важно, хранить вне компонента.
- Ответ RPC, который пришёл поздно, не должен перезаписать более новый: счётчик
  запросов в `useRef`, применять только ответ последнего. Отмена через cleanup
  `useEffect` не покрывает кнопку «Обновить», которая зовёт загрузку напрямую.
- Проверка: headless на 1280, 1100, 900, 600 и 400 px, элементы с
  `scrollWidth > clientWidth` и вылезающие за правый край — ноль.
