Your eXpress messenger chats, for the agents you allow.

Ask in plain words: "what did the team write to me", "write to Sasha Volkov that
I'll be late", "when the project chat has unread messages, tell me what is going
on there". The agent finds the chat or the colleague by the words you use —
names in Cyrillic or Latin, in any order, diminutives, chat names with mixed
alphabets — reads the last messages without marking them read, and sends a
message on your behalf after you confirm it in a system window.

**Answers in a thread, with a mention.** "Answer under my message about the
release and tag Alexander": the agent finds the message by a piece of its text,
opens its thread and picks the person in the client's own "@" list, so they get
a notification. The window shows the message and the person too.

**Watch rules.** After you confirm a rule in a system window, bb starts a thread
when the watched chat gets unread messages. It reads them and sums up who writes
what and what is expected from you, at most once per pause you set. That thread
can only read its own chat: it cannot send, change rules or run commands.

**No bot, no admin access.** The plugin drives the official eXpress web client
in a browser without a window on your own machine, signed in as you. Messages
are decrypted by the client itself.

**Who gets the chats.** Only the agents listed in the plugin settings get the
tools, each call checks the model the thread runs now, and a thread that has
read chats cannot be continued with another model. The server keeps no
messages; the directory of chats stays on your machine.

Needs Google Chrome, Microsoft Edge or Chromium on the machine that signs in.
Interface in English and Russian.
