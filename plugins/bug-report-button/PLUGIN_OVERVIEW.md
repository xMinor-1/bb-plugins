A small bug button on every screen of bb that opens your bug report form.

## What you get

- A button at the right edge of the window, on every route, also with the sidebar collapsed
- One click opens your form in the system browser, or in a new tab on the web
- No button at all until an address is set

Set `formUrl` and, if you like, `label` in the plugin settings. The plugin sends nothing anywhere.
