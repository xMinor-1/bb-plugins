# File Manager

Панель bb для работы с файлами на сервере: дерево директорий, загрузка и
скачивание файлов, в том числе больших — потоком, без ограничения в 25 МБ,
которое накладывает `bb.sdk.files`.

**Статус: спецификация готова, реализация не начата.** В репозитории лежит
каркас (`bb plugin new`) и полный контракт реализации — [SPEC.md](SPEC.md):
архитектурное решение и его обоснование, готовый `contract.ts` с RPC-схемами,
таблица HTTP-маршрутов для передачи байтов, правила защиты от выхода за корень,
дерево компонентов фронтенда, регистрация панели и план тестов.

Спека написана так, чтобы бэкенд, фронтенд и упаковку можно было делать
параллельно, и опирается на проверенные исходники bb 0.39.0 /
`@get-bb/plugin-sdk` 0.4.8. Открытые вопросы собраны в §14.

## Ключевые решения из спеки

- Бэкенд — обычная фабрика `bb.server` поверх `node:fs`; ни `bb.host`, ни
  `bb.sdk.files` не используются.
- Метаданные идут через `bb.rpc`, байты — через потоковый `bb.http.route`
  (chunked upload, download с поддержкой `Range`).
- Корень жёстко ограничен `/home/coder`, путь проверяется через `realpath`.

## Установка

```sh
bb plugin install git:https://github.com/xMinor-1/bb-plugins.git@main --plugin file-manager
```
